# Demo Locutivo - Zoe

¡Hola! Te doy la bienvenida a mi repositorio de locución. 

Este espacio alberga la muestra de mi trabajo vocal, diseñada para presentar la flexibilidad y matices de mi voz adaptados a diferentes proyectos y audiencias.

## Contenido del Demo

* **Introducción personal:** Un segmento dinámico y conversacional donde comparto mi trayectoria de formación locutiva con un estilo cercano y natural.
* **Aviso institucional:** Una demostración corporativa y formal que transmite seriedad, proyección y confianza para marcas o entidades.
